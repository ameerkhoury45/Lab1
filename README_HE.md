# מעבדה 2 - מסך כניסה למערכת GCM

הפרויקט מרחיב את מעבדה 1 עם מסך התחברות ב-JavaFX.
מעבדה 1 נמצאת בענף `main`, ומעבדה 2 בענף `lab2`:
https://github.com/ameerkhoury45/Lab1/tree/lab2
קובץ הקלט הוא `Users.txt`. הקובץ `expected-out.txt` מכיל את פלט הדוגמה
של מעבדה 1 לצורך השוואה.

## 1. פתיחה והרצה

1. פתח ב-IntelliJ את `pom.xml` שבשורש הפרויקט כפרויקט Maven.
   בעבודה עם קובץ ZIP יש לחלץ אותו קודם. בעבודה עם המאגר יש לבחור בענף `lab2`.
2. בחר JDK 17 או JDK 21 ב-Project SDK וב-Maven Runner.
   הקוד מכוון ל-Java 17 ומשתמש ב-JavaFX 21.0.13.
3. בצע Reload לפרויקט בחלונית Maven והמתן להורדת התלויות.
4. ודא ש-`Users.txt` נמצא באותה תיקייה שבה נמצא `pom.xml`.
5. פתח Terminal בתיקייה זו והריץ:

```text
mvn clean compile
mvn javafx:run
```

אם `mvn` אינו מזוהה, התקן Maven והוסף את תיקיית `bin` שלו ל-PATH,
בהתאם להנחיות המטלה. אחר כך פתח מחדש את הטרמינל או את IntelliJ.
אפשר גם להפעיל את היעד `javafx:run` מתוך חלונית Maven ב-IntelliJ.
אין צורך להוריד JavaFX SDK בנפרד: התלויות מוגדרות ב-`pom.xml`.

להתקנה לפי ההנחיות:

- Maven: https://maven.apache.org/install.html
- Scene Builder: https://gluonhq.com/products/scene-builder/

לאחר התקנת Scene Builder, הגדר את נתיב קובץ ההפעלה שלו בהגדרות JavaFX
של IntelliJ. קובצי ה-FXML נכתבו ידנית, כפי שהמטלה מתירה, וניתן לפתוח
ולערוך אותם גם ב-Scene Builder.

## 2. ניסיון התחברות

דוגמה למשתמש תקין שכבר נמצא בקובץ:

```text
Username: hello@world.net
Password: 01041972^H
```

אחרי לחיצה על Login ייטען מסך Welcome. סיסמה שגויה תציג הודעה אדומה
בתוך מסך הכניסה. הסיסמה מוסתרת בזמן ההקלדה באמצעות `PasswordField`.
אפשר ללחוץ Enter להפעלת כפתור הכניסה.

ההשוואה לשם המשתמש ולסיסמה היא מדויקת ורגישה לאותיות גדולות וקטנות.
אין הסרה אוטומטית של רווחים משדות מסך הכניסה, ואין שינוי של הסיסמה.

להרצה עם קובץ קלט אחר, שהנתיב שלו אינו כולל רווחים:

```text
mvn javafx:run -Djavafx.args=other-users.txt
```

בהרצה הרגילה, תוכנית ה-GUI קוראת את `Users.txt` פעם אחת לפני הצגת המסך.
אם שינית את הקובץ בזמן הריצה, סגור את התוכנית והפעל מחדש.

## 3. חלוקת הקוד

| קובץ | תפקיד |
| --- | --- |
| `src/main/java/User.java` | המחלקה המקורית ממעבדה 1, ללא שינוי בכללי התקינות. |
| `src/main/java/UserFileReader.java` | קריאת הקובץ, דיווח על שורות שגויות והחזרת `ArrayList<User>` של משתמשים תקינים. |
| `src/main/java/UsersApp.java` | שמירת התנהגות תוכנית הקונסול המקורית; משתמשת כעת בקורא הקבצים המשותף. |
| `src/main/java/LoginApp.java` | טעינת המשתמשים, הפעלת JavaFX, הצגת מסך הכניסה והגדרת פעולת הסגירה. |
| `src/main/java/LoginController.java` | טיפול בכפתור Login, התאמת זוג הפרטים, הצגת שגיאה ומעבר למסך הבא. |
| `src/main/java/WelcomeController.java` | הצגת שם המשתמש שהתחבר. |
| `src/main/resources/login.fxml` | מבנה מסך הכניסה וחיבור הכפתור ל-Controller. |
| `src/main/resources/welcome.fxml` | מבנה מסך Welcome. |
| `pom.xml` | הגדרת Maven, גרסאות התלויות ונקודת הכניסה `LoginApp`. |

לוגיקת קריאת הקובץ שהייתה בתוך `UsersApp` הועברה ל-`UserFileReader`.
כך תוכנית הקונסול ותוכנית ה-GUI משתמשות באותה בדיקה, בלי לשכפל אותה.
המחלקות נשארו ללא `package`, כמו בקוד המקורי. אין צורך ב-`module-info.java`.

## 4. התאמה לדרישות

- בכל שורה מתבצע ניסיון ליצור `User`. אם הבנאי זורק חריגה, השורה אינה נכנסת לרשימה.
- הרשימה נטענת לפני פתיחת המסך. שורות שגויות מדווחות בטרמינל, כמו במעבדה 1.
- שם המשתמש והסיסמה חייבים להתאים לאותו אובייקט `User` ברשימה.
- כישלון התחברות מוצג ב-`Label` בתוך המסך. אין `Alert` ואין חלון קופץ.
- בהצלחה נטען `welcome.fxml`, ונוצרת ממנו `Scene` חדשה באותו `Stage`.
  זה תואם להנחיה בעמוד 5 של מעבדה 2 להחליף מסך ולטעון FXML חדש.
- ה-Stage משותף לשני המסכים. ה-handler של סגירת החלון קורא ל-`Platform.exit()`.
- הקלט נקרא בקידוד UTF-8; נתמך גם סימון BOM בתחילת הקובץ.
- אם הקובץ חסר או אינו ניתן לקריאה, תוצג הודעה במסך והכניסה תיחסם.
- קובץ ריק או קובץ שכל שורותיו שגויות יפיקו רשימה ריקה; שום התחברות לא תצליח.
- תוכנית ה-GUI אינה זקוקה ל-`out.txt`. תוכנית מעבדה 1 עדיין יוצרת אותו.

רשימת הסימנים המותרים בסיסמה נשמרה מהקוד ומההבהרה המתועדת בדוח מעבדה 1:

```text
!@#$%^&*()_+-=
```

## 5. מבנה המאגר

הענף `main` שומר את מעבדה 1. הענף `lab2` מכיל את תוספת ה-GUI,
את מבנה Maven ואת קורא הקבצים המשותף.

הקישור הישיר למעבדה 2:
https://github.com/ameerkhoury45/Lab1/tree/lab2

אין לפתוח כפרויקט את `out/production` או את `.idea`; יש לפתוח את
התיקייה המכילה את `pom.xml` ואת `src`.

```text

```

```text
fc.exe /b out.txt expected-out.txt
```
